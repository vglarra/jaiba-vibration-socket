# TPU Hex Socket: Piezo Pad Vibration Damper

A parametric Blender script that generates a hexagonal TPU socket. It is glued over each hexagonal sensor pad of a piezo percussion tray, to isolate the pads from each other and damp vibration. One socket is printed per pad (16 in total).

The tray this fits is generated by a separate Blender script (`flat_hex_plate-Walls2`). All default dimensions were taken from that script so the two parts mate.

> **Status:** the script has passed a syntax check but has not yet been run in Blender or printed. Treat the console checks and the first test print as the real validation.

## Geometry

All hexes are **pointy-top** (flats facing ±X, corners at 30° + 60°·i), the same convention as the tray. All hex sizes are **flat-to-flat**, not side length.

| Feature | Value |
|---|---|
| Pad (tray inner platform) | 78 mm flat-to-flat, 5 mm tall |
| Socket interior | 78 mm flat-to-flat (plus optional clearance) |
| Wall thickness | 3 mm |
| Socket outer | 84 mm flat-to-flat (78 + 2 × 3) |
| Overall height | 26 mm (matches the tray's 26 mm walls) |
| Underside recess | z = 0 to 5 mm, open at the bottom, slips over the pad |
| Floor slab | z = 5 to 8 mm (3 mm thick) |
| Cup | z = 8 to 26 mm, 18 mm interior depth, open at the top |
| Wire hole | 12 mm diameter, through the floor slab, 28 mm from center toward the left flat (angle 180°) |

### Why 84 mm outside

The tray's pads are 78 mm wide on an 84 mm pitch, so neighboring pads are 6 mm apart. Two 3 mm socket walls fill that gap exactly, and adjacent sockets touch when glued. Because the outer size equals the tile pitch, adding fit clearance makes neighboring sockets overlap by 2 × the clearance (see below).

## Usage

1. Open Blender (a recent version; the script tries `wm.stl_export` first and falls back to the older exporter).
2. Open the **Scripting** workspace, load `tpu_hex_socket.py`, and run it.
3. The console prints the derived dimensions plus mesh checks:
   - non-manifold edges (expect 0)
   - volume compared with the analytic expectation
   - the same two checks again after the wire hole cut
4. An STL named `tpu_hex_socket.stl` is written next to the `.blend` file, or to your home folder if the file is unsaved.
5. Slice the STL and print it 16 times.

Re-running the script deletes and rebuilds the `TPU_Socket` object.

## Parameters

Everything is at the top of the script (all in mm):

| Parameter | Default | Notes |
|---|---|---|
| `PAD_FLAT` | 78.0 | Pad flat-to-flat |
| `PAD_HEIGHT` | 5.0 | Sets the underside recess depth |
| `WALL_T` | 3.0 | Wall thickness |
| `FLOOR_T` | 3.0 | Floor slab thickness |
| `TOTAL_H` | 26.0 | Overall height. Cup depth = `TOTAL_H - PAD_HEIGHT - FLOOR_T` |
| `FIT_CLEARANCE` | 0.0 | Extra room per side around the pad |
| `WIRE_HOLE` | True | Toggle the wire hole |
| `WIRE_HOLE_DIAMETER` | 12.0 | |
| `WIRE_HOLE_OFFSET` | 28.0 | Distance from hex center |
| `WIRE_HOLE_ANGLE` | 180 | Degrees. 180 is toward the left flat |
| `EXPORT_STL` | True | |

## Design notes

- **No booleans for the body.** The hex body is built directly in bmesh, so it is watertight by construction. This avoids the boolean solver failures the tray script had to work around.
- **One boolean for the wire hole.** A vertical cylinder cut through a flat slab is simple enough for the solver. The cutter extends 1 mm past the slab on both sides so it never sits on a coincident face. The script verifies the result by comparing the removed volume with the expected cylinder volume.
- **Tray alignment.** The wire hole uses the tray's own values (12 mm, 28 mm from center, 180°), so the holes line up when the socket is glued in the same orientation as the tray's tiles.

## Known issues and printing notes

- **Fit clearance.** `FIT_CLEARANCE` defaults to 0. TPU may need roughly 0.1 to 0.2 mm per side, but any value above 0 pushes the outer hex past the 84 mm pitch. If clearance is needed, thin the walls to compensate so the outer size stays at 84 mm.
- **Bridging.** The 78 mm hex floor is a large bridge in either print orientation, and TPU bridges poorly. Printing cup-up with support inside the 5 mm underside recess is the likely approach. This is untested.
- **Untested.** Print settings, glue choice, and the real-world fit on the tray have not been verified yet.
